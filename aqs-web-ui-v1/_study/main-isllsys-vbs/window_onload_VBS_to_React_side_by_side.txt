WHAT THIS FILE IS:
  Main_ISLLSYS_20010101.vbs is the top-level browser window hosting the AQS frameset (menu, tree,
  content frames). Its window_onload runs once when the window opens: registers the window, decides
  the screen layout from the policy id, parses permission XML, and starts a chained load of menu ->
  tree -> first page. This is DIFFERENT from Eebrowser.vbs window_onload (which initializes a single
  page).

REACT TARGET:
  Converted to src/engine/load/shell-load.ts, split into shellLoad() [route loader, runs BEFORE
  render] + useShellLoad() [effect, runs AFTER first render]. Wired into router.tsx (loader on the '/'
  route) and AppLayout.tsx. Shipped and verified running.

LEGEND:  [CONVERTED]=direct code in shell-load.ts   [MOVED ELSEWHERE]=another engine file
         [FRAMEWORK HANDLES]=React Router/MUI does it   [ELIMINATED]=not needed in the SPA
