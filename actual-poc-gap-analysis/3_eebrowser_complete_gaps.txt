3. EEBROWSER.VBS COMPLETE — GAP ANALYSIS (all 32 routines vs actual POC)
================================================================================
VBS file: Eebrowser.vbs (~1,235 lines, 32 routines)
Actual POC: aqs-web-ui (hitanshu/experimental branch)

Eebrowser.vbs is the PER-PAGE CONTROLLER — it runs inside every content frame.
Many of its routines are thin delegation stubs that call through mobjAQSMain
to Main_ISLLSYS routines. The actual work happens in Main_ISLLSYS; Eebrowser
wires page-level events to the shell's dispatcher.

Legend:  DONE     = implemented in actual POC
        PARTIAL  = concept exists but incomplete
        GAP      = not implemented
        N/A      = not needed in SPA

KEY INSIGHT: Eebrowser has two kinds of routines:
  A) Delegation stubs (call mobjAQSMain.XXX) — these are N/A because the
     SPA calls handlers directly, no cross-frame delegation needed.
  B) Real logic (CallServer, window_onload, etc.) — these need mapping.

CORE SERVER COMMUNICATION (Lines 654-857)
================================================================================

#15 CallServer (Sub, ~203 lines)
    PURPOSE: THE HEART OF EEBROWSER. Builds XML payload from
             marrSessionInformation + marrEEData + marrServerCallXML,
             POSTs synchronously via MSXML2.XMLHTTP to xmlservercall.asp,
             parses response, extracts ListItems and BrowserCommands,
             delegates to mobjAQSMain.ExecuteBrowserCommands.
    STATUS: DONE
    POC FILES: src/services/page-data.ts (95 lines) — the data exchange
             + src/utils/http-instance.ts (219 lines) — axios instance
             + src/handlers/common/payload.ts (282 lines) — builds EEData
             + src/handlers/common/command.ts (274 lines) — processes commands
    HOW: page-data service POSTs JSON to /ui/page/data. Response contains
         sessionInformation, eeData, listItems, browserCtl (commands).
         Axios handles HTTP. handlerForBrowserCommands dispatches commands.
    GAP: None — this is the most complete part of the POC.
